# meowmarism website

The public website of [meowmarism](https://github.com/meowmarism-official): landing page, setup guide, documentation and the legal pages.

Plain static HTML, CSS and a little JavaScript. No build step, no third-party requests: fonts, icons and scripts are all self-hosted.

```
public/     everything the web server serves
```

Open `public/index.html` through any static file server to preview it, for example `python -m http.server` inside `public/`.
