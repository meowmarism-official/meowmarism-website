Setup guide

Everything you need to get meowmarism LITE running on your own server.

1Install

On a Linux server (Debian, Ubuntu, Fedora or RHEL-based), run:

$ curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-lite/master/install.sh | bash

Nothing needs to be installed beforehand, not even Node.js. The script installs everything it needs, downloads the latest tagged release (not the development branch), installs it to /opt/meowmarism, and sets up a systemd service. Re-running the same command later updates it in place.

2Set a username and password

Before it prints anything else, the installer asks you to create the owner account right there in the terminal. This happens before the panel is ever reachable with no login, not as an afterthought once it's already exposed.

3Open the panel

The installer prints the exact address to open, detected from the machine itself: http://your-server-ip:8090. That's the controller: it lists every instance running on this host, lets you create new ones, and is the only thing that needs a login.

4Create an instance

Click the + button and pick a name, a server type (Vanilla, Paper, Purpur, Fabric, Forge or NeoForge), a Minecraft version and a port. meowmarism downloads and installs the server software for you. Click into the new instance once it's ready to reach its full dashboard: live console, players, mods, backups, and more.

5Configuration (optional)

These environment variables control the installed service. You generally never need to touch them by hand.

VariableDefaultApplies toPurpose
CONTROLLER_PORT8090controllerPort the instance list listens on
WORKER_PORT_BASE9090controllerFirst internal port handed out to a worker; each new instance gets the next free one

Everything else is in the documentation. The source lives on GitHub.
