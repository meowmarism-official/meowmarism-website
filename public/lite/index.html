meowmarismmeowmarismmeowmarismLITEby hexedmaya

A self-hosted control panel for your Minecraft servers. Run several servers side by side, each in its own process, with a live console, mods, backups and permissions. On your own hardware, with no cloud and no telemetry.

GitHubOpen docs

Install in one command

On a Linux server with systemd. Nothing needs to be installed beforehand, not even Node.js or Java.

$ curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-lite/master/install.sh | bash

The installer asks for the owner account before the panel starts, so it is never reachable without a login. Getting started

Everything to run your servers

The things you would otherwise do over SSH, in a browser.

Many servers, one panelVanilla, Paper, Purpur, Fabric, Forge and NeoForge. Each instance is its own process with its own console and statistics.
Live console and statisticsServer output and commands in real time, CPU, RAM, disk and network sampled every 50 ms, history up to 7 days.
Mods from ModrinthSearch, install with required dependencies, see and apply updates. Paper and Purpur use plugins.
Backups that protect youAutomatic tiered backups, one-click restore that keeps your current world aside, a backup before every upgrade.
SchedulerPlan backups, restarts, start and stop and console commands. Warn players before a restart.
Accounts and permissionsGive each person exactly the access they need, per instance. Presets or individual permissions.
Java handled for youMinecraft 26 needs Java 25? meowmarism installs the right runtime for that server, no sudo needed.
Safe upgrades and updatesUpgrade a server with a backup and a rollback. Update the panel from the panel, with a start test and automatic rollback.
Made for the internetLogin throttling, HTTPS behind Caddy or nginx, permissions enforced twice. No third-party requests.

Up and running in three steps

InstallRun the command above and set the owner account.
Create a serverPress +, pick a type and version. Everything is downloaded and set up.
PlayStart it, open the console, invite friends. Add mods whenever you like.
