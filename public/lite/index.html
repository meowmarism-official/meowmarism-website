A self-hosted control panel for your Minecraft servers. Run several servers side by side, each in its own process, with a live console, mods, backups and permissions. On your own hardware, with no cloud and no telemetry.

GitHubOpen docs

Install in one command

On a Linux server with systemd. Nothing needs to be installed beforehand, not even Node.js or Java.

$ curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-lite/master/install.sh | bash

The installer asks for the owner account before the panel starts, so it is never reachable without a login. Getting started

What sets LITE apart

Everything both editions share is on the main page. This is what LITE adds.

Many servers, one panelVanilla, Paper, Purpur, Fabric, Forge and NeoForge. Each instance is its own process with its own console and statistics.
Java handled for youMinecraft 26 needs Java 25? meowmarism installs the right runtime for that server, no sudo needed.
AutomationDaily restart with a warning countdown, sleep mode that stops an empty server and wakes it when someone joins, and automatic restart after a crash.
Events and audit logA timeline of joins, leaves, lag and crashes, and a log of every action taken in the panel.

Need hard limits?

Every server in its own Docker container with real CPU and RAM limits: meowmarism PROFESSIONAL. Both are free and open source.
