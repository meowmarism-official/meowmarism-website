Privacy

Applies only to this website, available at meow.melloo.me and meowmarism.melloo.me. Not to meowmarism itself.

What this page covers

This notice is about meow.melloo.me and meowmarism.melloo.me (the same site on two domains), the informational site you're on right now. It is not about the meowmarism software. meowmarism is self-hosted: the control panel and the Minecraft server data it manages live entirely on infrastructure operated by whoever runs it. meowmarism does not send anything from your instance to us, and there is no central meowmarism service that this website talks to on your behalf.

Server logs

Like effectively every website, requests to this domain pass through a reverse proxy and webserver that keep standard access logs: IP address, timestamp, the requested path, user-agent, and referrer. These logs exist for operating and securing the server (spotting abuse, debugging outages) and aren't used for tracking or shared with anyone.

No analytics, no cookies

This site runs no analytics, no tracking pixels, and sets no cookies. The animated background is a canvas animation that runs entirely in your browser and never sends anything anywhere.

No third-party resources

Every font, icon and script on this page is served from this same domain. Nothing is loaded from a CDN or any other third party. The one exception is the License page, which fetches the project's LICENSE file directly from raw.githubusercontent.com so it always matches the repo. That page causes your browser to make a request to GitHub. No other page on this site does.

Links to GitHub

The GitHub links on this site point to github.com/meowmarism-official. Clicking one takes you to GitHub, which is governed by its own privacy policy. Nothing is transferred there just by this page loading, only if you actually click through.
