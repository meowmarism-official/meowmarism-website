Instances

An instance is one Minecraft server with its own console, statistics and backups. In LITE it is a process on the host, in PROFESSIONAL a Docker container.

Creating an instance

Click + on the server list. The assistant asks for:

  • Name: letters and digits. If the name exists, a number is appended.
  • Server type and Minecraft version (and the loader version where needed).
  • Port: see below.
  • Memory: handed to the JVM. Leave room for the operating system and other instances.
  • Autostart: start the server whenever the panel starts.
  • Backup interval and how many backups to keep.

A progress view shows the download and installation. When it finishes, the instance appears in the list.

Ports

The assistant suggests a free port starting at 25565. A port is not free when another instance uses it or when another program is already listening on it. If you type a taken port, the next free one is used and you are told. When a server is started and its port is busy, it does not start and the console explains why.

Java

Each Minecraft version needs a minimum Java version. If the host has an older one, meowmarism downloads the right runtime (Temurin) into ~/meowmarism/java/<version> and uses it for that instance only, without touching the system Java. See Startup, Java and limits.

Icon and MOTD

New servers get the meowmarism icon and the MOTD hosted by meowmarism :3. Change the icon on the instance's Settings page (any image, scaled to 64 by 64) and the MOTD in server.properties. Restart the server to apply either.

Where files live

~/meowmarism/instances/<name>/   world, mods, server.properties, ...
~/meowmarism/backups/<name>/     world backups
~/meowmarism/java/<version>/     Java runtimes installed by meowmarism

Managing an instance

The Manage page inside an instance holds everything about the instance itself: startup options (memory, JVM flags, Java, CPU and RAM limits, autostart), the server software card for upgrades, and the danger zone.

Deleting an instance

Open Manage and use Delete instance... in the danger zone. This removes the instance from the panel and deletes its folder with the world, mods and configuration. You must type the instance name to confirm, and you can choose to delete its backups too. The Minecraft server has to be stopped first.

Careful

This cannot be undone. The panel refuses to delete a folder that contains the panel itself, your home directory, or something that does not look like a Minecraft server.
