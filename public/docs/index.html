Overview

meowmarism is a control panel for Minecraft servers that runs entirely on your own machine. There is no account, no cloud and no telemetry. It is plain Node.js with no framework and no database.

One controller listens on a single port (8090 by default). It starts one small worker process per instance, and every instance is reachable through the controller under /instance/<name>/. The Minecraft servers themselves are separate processes that the worker starts and stops. Restarting the panel does not touch a running server's settings, and stopping a server never stops the panel.

Instances

Create an instance with the + button. Pick a name, a server type, a Minecraft version and a port. meowmarism downloads and installs everything.

TypeNotes
VanillaThe official server jar.
Paper, PurpurLatest build for the chosen version. Uses plugins.
FabricPick the loader version.
Forge, NeoForgePick the loader version. The installer runs for you (needs Java).

New servers get the meowmarism icon and the MOTD hosted by meowmarism :3. Both can be changed per server: the icon on the Settings page, the MOTD in server.properties. You can also let a server start automatically when the panel starts.

Instances live in ~/meowmarism/instances/<name> and their backups in ~/meowmarism/backups/<name>, outside the instance folder.

Dashboard

Each instance has its own dashboard: live overview (CPU, RAM, disk and network sampled every 50 ms), performance history, players with moderation, the console with command access, server.properties editing, files, whitelist / operators / bans, backups, the scheduler, automation, an event timeline with an audit log, and system details.

Mods and plugins

The Mods page lists installed jars and lets you enable or disable them. Browse Modrinth searches only what is compatible with the instance's Minecraft version and loader, installs the newest release and adds required dependencies automatically. You can also pick a specific version.

The Updates tab identifies installed files by their hash, so mods you added by hand are found too. Update one or all. Replaced files move to mods-old (or plugins-old) instead of being deleted. Downloads are only accepted from Modrinth's CDN and verified against their SHA-512. Paper and Purpur use the plugins folder.

Backups

World backups run automatically on an interval you choose. Recent backups are all kept, older ones are thinned to one per hour and then one per day. Restoring puts the current world aside first, so nothing is lost by accident. A backup is also taken before every scheduled restart and before a server upgrade.

Scheduler

Plan backups, restarts, stop / start and console commands. A task repeats every day, on chosen weekdays, or every few minutes. Restarts and stops can warn players in chat first. Times use the server's local time. A task that was missed by more than ten minutes (for example during a reboot) is skipped, not run late.

Startup and limits

The Automation page has a Startup card: min and max memory, JVM flags (standard or Aikar's optimized G1GC set), extra JVM arguments, a specific Java binary, and an autostart switch. CPU and hard RAM limits use systemd cgroups when the host supports them, otherwise CPU is limited by pinning to cores. The card tells you what your host can enforce.

Changing extra JVM arguments or the Java binary needs the Files permission, because it lets someone run arbitrary code as the panel user.

Upgrading a server

The Server software card on the Automation page upgrades Minecraft or the loader. The server has to be stopped. meowmarism takes a world backup, saves the current launch files, installs the new version and keeps your JVM arguments. Roll back restores the old files and the world from that backup. Going to an older Minecraft version needs an explicit confirmation because it can damage the world.

Accounts

The installer creates the owner account before the service starts, so the panel is never reachable without a login. More accounts are created under Manage users with a preset (Viewer, Operator, Manager, Administrator) or individual permissions:

  • Per instance: view, console and players, start / stop, files, mods, backups, settings, remove. Set a default for all instances and override it per instance.
  • Panel-wide: manage users, create instances, update the panel.

Permissions are enforced by the controller and again by each worker. Failed logins are throttled per IP and username.

Updating the panel

The Update page shows the installed and the newest release and updates in place. By default all Minecraft servers must be stopped first; this can be switched off on the Settings page, in which case running servers are stopped briefly and started again. Before switching, the new version is start-tested on a spare port, and the old version stays on disk until the new one has run healthily. A version that fails the test or keeps crashing is rolled back automatically.

HTTPS and internet access

The panel speaks plain HTTP. For anything reachable from the internet, put it behind a reverse proxy that terminates HTTPS, let the panel listen on localhost only, and tell it a proxy is in front:

MEOWMARISM_HOST=127.0.0.1 MEOWMARISM_TRUST_PROXY=1 bash install.sh

Caddy:

panel.example.com {
    reverse_proxy 127.0.0.1:8090
}

nginx:

location / {
    proxy_pass http://127.0.0.1:8090;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    proxy_buffering off;
}

With the proxy setting on, the session cookie is Secure, HSTS is sent and login throttling uses the real client IP. Only enable it when a proxy really sets those headers. The panel warns you when it is opened over plain HTTP on a public address.

Uninstall

Run the installer again and choose Remove. It lists what will be deleted and asks you to type remove. Your instances, backups and accounts are only deleted if you additionally type delete everything.
