Introduction

meowmarism is a control panel for Minecraft servers that runs entirely on your own machine. No account, no cloud, no telemetry. It comes as LITE and PROFESSIONAL, and these docs cover both.

What it does

You install it once with a single command. From your browser you then create servers, start and stop them, watch the console and live statistics, manage mods, take backups, schedule restarts and share access with other people, each with exactly the permissions you choose.

How it works

One controller listens on a single port (8090 by default). It starts one small worker process per instance, and every instance is reachable through the controller under /instance/<name>/. The Minecraft servers themselves are separate processes that a worker starts and stops.

Restarting the panel does not change a server's settings, and stopping a server never stops the panel. Everything is plain Node.js with no framework and no database, and nothing is loaded from a third party.

Editions

LITE runs each server as a process on the host and is available today. PROFESSIONAL runs each server in a Docker container with hard CPU and memory limits and is in development. They share design, modules and these docs. The Editions page lists what is the same and where they differ.

Requirements (LITE)

ItemNeeded
Operating systemLinux with systemd (Debian, Ubuntu, Fedora or RHEL based). x64 or arm64.
Node.js18 or newer. The installer installs Node 20 if it is missing.
JavaInstalled by the panel when a server needs a newer version than the host has.
AccessA user with sudo for the install.
NetworkPort 8090 for the panel, plus the port of each Minecraft server (25565 and up).

PROFESSIONAL also needs Docker. Its installer offers to install it. See Docker and limits.
