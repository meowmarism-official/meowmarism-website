Editions

meowmarism comes in two editions. They look the same, work the same way and share these docs. They differ in how a Minecraft server runs.

Pages in these docs that apply to both editions have no label. Pages for one edition only carry a LITE or PRO label in the menu.

Which one should I use

  • You run a few servers for friends or yourself: LITE. It installs with one command and needs no Docker.
  • You run many servers, host for others, or need hard limits so one server cannot slow down another: PROFESSIONAL, once it has its first release.

Where PROFESSIONAL stands today

PROFESSIONAL is built separately from LITE and shares its design, its modules and these docs. It does not have every LITE page yet.
