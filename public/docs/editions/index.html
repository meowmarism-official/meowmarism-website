Editions

meowmarism comes in two editions. They look the same, work the same way and share these docs. They differ in how a Minecraft server runs.

At a glance

Pages in these docs that apply to both editions have no label. Pages for one edition only carry a LITE or PRO label in the menu.

Which one should I use

  • You run a few servers for friends or yourself: LITE. It installs with one command and needs no Docker.
  • You run many servers, host for others, or need hard limits so one server cannot slow down another: PROFESSIONAL.

What PROFESSIONAL has

PROFESSIONAL has its own code and shares design, modules and these docs with LITE.

  • An installer that also installs Docker, and instances as containers (Vanilla, Paper, Purpur, Fabric, NeoForge, Forge).
  • Hard CPU and memory limits per instance, console, files, mods, backups, scheduler, players and access lists.
  • Minecraft version upgrade with rollback, updates from the panel, several accounts with permissions per instance.

Not available yet: managing several hosts from one panel. Both editions install with one command, see Getting started.
