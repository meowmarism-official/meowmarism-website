Backups

Automatic world backups with sensible retention and a restore that never destroys your current world.

Automatic backups

A backup of the world folder runs on the interval you set (hours) and is kept up to a maximum count. The Backups page and the instance's Automation page hold the settings. A backup is also taken before every scheduled restart and before a server upgrade.

Retention

Recent backups are all kept. Older ones are thinned to one per hour after three hours, and to one per day after a day, so many days fit without piling up near-identical copies. The maximum count still applies on top.

Manual backups

Press Back up now at any time, also while the server is running. The panel pauses saving briefly so the copy is consistent.

Restoring

Restore a backup with the restore button. The Minecraft server is stopped, your current world is moved aside (not deleted) and the backup is extracted. If extraction fails, the previous world is put back.

Where they are

~/meowmarism/backups/<instance>/world-2026-01-01T04-00-00-000Z.tar.zst

Backups are outside the instance folder, so they survive when you delete an instance (unless you choose to delete them too). They use zstd compression when it is installed, otherwise gzip.

What is not covered

Only the world folder is backed up. Servers that keep separate world folders (some Paper setups) need those backed up another way. Before every backup the panel estimates the size of the world and skips the backup if less than the reserve would stay free afterwards. The reserve is 5 GB by default and can be changed per instance under Keep GB free in the backup settings.
