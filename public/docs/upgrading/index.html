Upgrading a server

Move a server to a newer Minecraft or loader version and undo it if needed.

On the instance's Manage page, the Server software card shows what is installed and offers Upgrade.... The Minecraft server must be stopped.

What happens

  1. Backup

    A world backup is taken first. If it fails, nothing is changed.

  2. Launch files saved

    The current jar, run.sh and JVM arguments are copied into .upgrade/ inside the instance.

  3. New version installed

    Your JVM arguments are kept. If the new version needs a newer Java, it is installed for you.

  4. Panel restarted

    The instance's panel restarts so it knows the new version. The server is not started automatically.

Rolling back

Roll back restores the saved launch files and the world from the backup taken before the upgrade. Everything played after the upgrade is lost, and the dialog says so before you confirm.

Going to an older version

Older Minecraft versions can damage a world that was already opened by a newer one. The panel therefore asks for an explicit confirmation before it allows it.

Permissions

Upgrading needs both settings and files on the instance.
