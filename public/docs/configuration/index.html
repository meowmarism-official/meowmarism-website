Configuration

What can be configured and where everything is stored.

Environment variables

Set them on the systemd service, or when running the installer.

VariableDefaultPurpose
CONTROLLER_PORT8090Port the panel listens on
WORKER_PORT_BASE9090First internal port for instance panels (loopback only)
MEOWMARISM_HOST0.0.0.0Address the panel listens on
MEOWMARISM_TRUST_PROXYoffTrust X-Forwarded-* headers from a reverse proxy
MEOWMARISM_DATA_DIR~/meowmarismWhere instances, backups and Java runtimes are stored

The installer also reads MEOWMARISM_DIR (install folder, default /opt/meowmarism), MEOWMARISM_SERVICE (service name) and MEOWMARISM_PORT. Without MEOWMARISM_PORT the installer asks which port the panel should use (default 8090, the next free one if that is taken). To change it later, run the installer again and choose More options, then Port. Updating keeps the port you chose.
