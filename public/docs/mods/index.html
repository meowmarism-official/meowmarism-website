Mods and plugins

Search Modrinth, install with required dependencies and keep everything up to date, without touching SSH.

The Mods page has three tabs: Installed, Browse Modrinth and Updates. Paper and Purpur servers use the plugins folder, all other types use mods. Vanilla servers have neither.

Installed

Lists every jar in the folder and lets you disable or enable it. Disabled files move to disabled_mods and are not loaded. Changes take effect after a server restart.

Browse Modrinth

The search only shows projects that are compatible with the instance's Minecraft version and loader. Install takes the newest release and adds required dependencies automatically. Versions lets you pick a specific version instead.

Updates

Installed files are identified by their hash, so mods you added by hand are found too. The tab shows:

  • mods that have a newer release, with Update and Update all;
  • mods that have no compatible version for this server;
  • files that are not on Modrinth and therefore not checked.

Replaced files move to mods-old (or plugins-old) instead of being deleted, so you can go back.

Safety

Downloads are only accepted from Modrinth's CDN and are checked against their SHA-512 and size. A file that fails the check is discarded.

Permissions

Installing and updating needs the mods permission on the instance.
