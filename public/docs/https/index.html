HTTPS and internet access

The panel speaks plain HTTP. For anything reachable from the internet, terminate HTTPS in front of it.

Important

Over plain HTTP, passwords and sessions can be read by anyone on the path. The panel shows a warning when it is opened over HTTP on a public address.

1. Listen on localhost and trust the proxy

At install time:

MEOWMARISM_HOST=127.0.0.1 MEOWMARISM_TRUST_PROXY=1 bash install.sh

Alternatively add both as Environment= lines to the service, or switch on This panel runs behind an HTTPS reverse proxy on the panel's Settings page.

With the proxy setting on, the session cookie is Secure, HSTS is sent and login protection uses the real client IP from X-Forwarded-For. Only enable it when a proxy really sets those headers.

2. Caddy

Caddy gets and renews certificates by itself.

panel.example.com {
    reverse_proxy 127.0.0.1:8090
}

3. nginx

location / {
    proxy_pass http://127.0.0.1:8090;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    proxy_buffering off;
}

proxy_buffering off matters: the live console and statistics use server-sent events.

Minecraft ports

The reverse proxy only covers the panel. Players still connect directly to each server's Minecraft port, so open those ports in your firewall.
