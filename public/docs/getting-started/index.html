Getting started

From an empty Linux server to a running Minecraft server in a few minutes.

Choose an edition

LITE is available today. Run this on your Linux server:

curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-lite/master/install.sh | bash

PROFESSIONAL uses Docker and installs the same way. Its installer also offers to install Docker:

curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-professional/master/install.sh | bash

The steps below describe LITE. PROFESSIONAL asks for the same owner account and prints the panel address the same way, and it stores its data in ~/meowmarism-pro. See Docker and limits.

  1. Install

    On a Linux server run:

    curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-lite/master/install.sh | bash

    The script downloads the latest tagged release (not the development branch), installs it to /opt/meowmarism and sets up a systemd service. Nothing needs to be installed beforehand, not even Node.js.

    Tip

    Prefer to read the script first? Download it with curl -fsSLO …/install.sh, read it, then run bash install.sh.

  2. Set the owner account

    Before anything is started the installer asks for a username and a password (twice, minimum 8 characters). The account is written before the service starts, so the panel is never reachable without a login.

  3. Open the panel

    The installer prints the address, detected from the machine: http://your-server-ip:8090. Log in with the owner account.

  4. Create an instance

    Click the + button. Pick a name, a server type, a Minecraft version and a port. meowmarism downloads and installs everything, including the right Java version if the host does not have it. See Instances.

  5. Start it

    Open the instance and press Start. The console shows the server starting, and the overview turns green when it is ready.

Note

Reaching the panel from the internet? Read HTTPS and internet access first. The panel speaks plain HTTP by itself.

Running the installer again

Run the same command on a server that already has meowmarism and it finds the install. It offers U to update (only when a newer release exists), M for more options and C to cancel. M opens a second choice:

  • O: owner reset. Set a new owner username and password, for example when the password is lost. Everyone is signed out. Instances and members are kept.
  • R: remove meowmarism, see Uninstall.

What was installed

WhereWhat
/opt/meowmarismThe panel itself
/etc/systemd/system/meowmarism.serviceThe service that keeps it running
~/meowmarism/instancesYour Minecraft servers
~/meowmarism/backupsWorld backups
~/.meowmarism-*.jsonAccounts, instance list, settings
