Scheduler and automation

Do things on a schedule, and let the panel recover from crashes on its own.

Scheduled tasks

Open Scheduler inside an instance and press Add task. A task has an action and a schedule.

ActionWhat happens
BackupTakes a world backup.
RestartRestarts the server. Optionally warns players in chat first.
Stop / StartStops or starts the server. Stop can warn players first.
Console commandSends a command to the server, for example say Back in 5 minutes.
ScheduleMeaning
Every dayAt a time you choose.
On weekdaysOnly on the days you tick, at a time you choose.
Every few minutesEvery 5 minutes up to every 7 days.

Times use the server's local time. The table shows the last and the next run, and Run now starts a task immediately.

Missed tasks

A task that was due while the panel was not running (for example during a reboot) is skipped if it is more than ten minutes late, not run at a surprising moment.

Permissions

Creating a task needs the settings permission plus the permission of its action: backups for backups, power for restart, stop and start, console for commands. This keeps someone with settings access from running console commands.

Daily auto-restart

On the Automation page: restart once a day at a chosen time, with a chat countdown and a backup beforehand.

Crash auto-restart

Restarts the server after an unexpected crash after a short delay. It stops trying after too many crashes in an hour so a broken mod cannot loop forever.

Sleep mode

Stops the server when nobody has been online for the chosen number of minutes and starts it again as soon as someone tries to join. The server stays visible in the multiplayer list while it sleeps.
