Updating meowmarism

Update from the Update page. The old version stays until the new one has proven itself.

From the panel

The Update page shows the installed and the newest release. A yellow dot on the Update icon in the sidebar tells you when a newer one is available. The panel checks every five minutes, and Check for updates checks immediately. Press Update now.

Running servers

meowmarism recommends stopping all servers before updating. When servers are running, Update now asks you to Cancel or Continue. On Continue the panel stops the running servers, waits until they have saved and shut down, installs the update and starts them again.

Safety net

  1. Download and syntax check

    The release is downloaded and every script is checked before anything changes.

  2. Start test

    The new version is started on a spare port with no instances attached. If it does not answer within 25 seconds, the old version stays and your servers are started again.

  3. Old version kept

    After the swap the old version stays on disk. Only after the new one has run healthily for a minute is it removed.

  4. Crash guard

    If the new version keeps crashing on startup, the old one is swapped back in automatically.

If a rollback happened, the Update page tells you why.

From the terminal

Run the installer again. It compares the installed and the latest version and only offers Update when they differ. Remove is offered as well.

What is kept

An update replaces only the panel program. Instances, backups, accounts and settings are not touched.
