Performance history

Ranges are 1 minute, 5 minutes, 15 minutes, 1 hour, 24 hours and 7 days. History is saved once a minute and when the panel stops, so it survives panel restarts. While the server is off the charts show zero, and time when the panel itself was not running is drawn as a flat zero line. Drag on a chart to zoom, double click to return to live.

Console

Commands typed here go straight to the server. Anyone with the console permission can run any server command, so give it carefully. See Accounts and permissions.

Files

The file manager works inside the instance folder only. Click a folder to open it. For a file, press Edit to open it in the built-in editor, or Download. Deleting a file or folder asks for confirmation with a dialog that names the path.

The editor

  • Text files up to 2 MB open in the editor. Binary files such as jars, archives, images and world data can only be downloaded.
  • Line numbers, the cursor position and colors for .properties, .json, .yml and .toml files.
  • Ctrl+S (or Save) writes the file. The write is atomic, and the file's permissions and line endings (LF or CRLF) are kept.
  • If the file changed on the server after you opened it, the editor asks before overwriting it.
  • Saving JSON that is not valid asks first. Closing with unsaved changes asks first.
  • Most server files only take effect after a restart.

Events and audit

The timeline records starts, stops, crashes, restarts, lag warnings, settings changes and player joins. The audit log records every action taken in the panel.
