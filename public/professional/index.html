For hosting providers and communities that run many servers. It builds on the same foundations as LITE and runs every server in its own Docker container with hard limits. This is an early release: it has the features of LITE that matter for hosting, and some things are still to come.

What it does

Available now, and what is still planned.

Docker isolationEvery instance in its own container, with its own network and volumes, and an image per Minecraft version and loader.
Real resource limitsHard CPU and RAM limits per instance through container cgroups, not just a JVM heap setting.
Several servers, one panel (planned)Today one panel manages all containers on one host. Managing several physical hosts from one place is planned.
The same permission modelThe permission model, look and feel of LITE: accounts with rights per instance, German, French and Spanish.

Built on the same foundations

LITE and PROFESSIONAL share design, brand and the permission model through meowmarism core. Everything you learn in LITE carries over.

LITE keeps goingLITE stays free and open source. PROFESSIONAL does not replace it.
Free and open sourcePROFESSIONAL is free and open source under the same license as LITE. The name says who it is for, not that it costs anything.
