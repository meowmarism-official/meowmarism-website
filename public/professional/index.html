The Docker edition of meowmarism. Every Minecraft server runs in its own container with hard CPU and RAM limits, managed from one panel with the same look and permissions as LITE. For hosting providers and communities that run many servers.

GitHubOpen docs

Install in one command

On a Linux server with systemd. Nothing needs to be installed beforehand, not even Node.js or Docker.

$ curl -fsSL https://raw.githubusercontent.com/meowmarism-official/meowmarism-professional/master/install.sh | bash

The installer asks for the owner account before the panel starts, so it is never reachable without a login. Getting started

What sets PRO apart

Everything both editions share is on the main page. This is what PRO adds.

Docker isolationEvery instance in its own container, with its own network and volumes, and an image per Minecraft version and loader.
Real resource limitsHard CPU and RAM limits per instance through container cgroups, not just a JVM heap setting.
Docker set up for youThe installer installs Docker if it is missing and keeps your servers running in their containers while the panel updates.

Only a few servers?

No Docker needed: meowmarism LITE runs every server as a process on the host. Both are free to use and source-available.
